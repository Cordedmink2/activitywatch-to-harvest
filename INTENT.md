# Intent

## What this is for

A consultant bills several clients from one machine and cannot honestly reconstruct Tuesday from
memory. This reconstructs the workday from local activity data, proposes per-client billable
blocks, and posts them once the user confirms. It does the remembering; the user does the
confirming.
